## Install or upgrade

```bash
gh release download v0.2.1 --repo wrestle-R/Spotify-Tui --pattern download-linux.sh
less download-linux.sh
bash download-linux.sh --destination ./spotify-tui-linux
bash ./spotify-tui-linux/install.sh
~/.local/bin/spotify-tui --demo
```

Use a new directory for each download. Before upgrading, exit the old UI and stop its helper with `spotify-tui stop`. The installer preserves your XDG config, keyring and provider data, and retains prior build directories. Both installed version commands should report `0.2.1`. A custom prefix is supported with `install.sh --prefix /your/prefix`.

The repository is private; downloads require authenticated GitHub access. This package is for Linux x86_64, tested on Arch, and requires glibc 2.39+ and `libgcc_s`. Real audio requires Spotify Premium and [separate Soloist/account setup](../SETUP.md).

## Validation

- The prior version's Go/Rust checks and real terminal walkthrough cover the unchanged playback/UI implementation.

The archive contains both binaries, `install.sh`, README, changelog, version detail pages, setup/test documentation and a generic demo screenshot. It contains no account data or Soloist executable. Checksums are supplied; packages are unsigned.

## Known issues

The [v0.2.0 limitations](v0.2.0.md#known-issues) still apply. Offline downloads remain unavailable, provider session recovery can occasionally need `c`, and full liked-song sequencing, playlist offsets, search paging, tray/MPRIS integration and long-session resource/stability checks remain outstanding. This packaging fix does not change those capabilities.
