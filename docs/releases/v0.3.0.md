# v0.3.0

28 October 2026 · **Stable** · Linux x86_64

## Tray controls, direct updates and confirmed pause/resume

A small Linux tray companion now starts with the TUI when the desktop has a StatusNotifier host. It uses the approved music-note and sound-wave logo. Open the TUI from the tray, pause/resume, skip tracks, stop everything or leave audio running when quitting the tray. No GTK/cgo dependency is needed.

Startup checks the latest stable GitHub release in the background. Ctrl-U downloads and verifies it, installs a matching Go/Rust pair, then restarts. The command-line equivalents are `check-updates` and `update`. Updates activate a single shared pointer after validation and retain previous builds for rollback. Public downloads no longer need GitHub login.

Space and the tray's toggle now decide pause/resume at the Rust helper using its current state. Play/pause replies wait for provider acceptance and matching playback state. A delayed older poll cannot reverse the UI's displayed state. Playing/Paused labels now describe current playback explicitly.

## Install or upgrade

Exit older player versions, then run:

```bash
curl -fL https://github.com/wrestle-R/Spotify-Tui/releases/download/v0.3.0/download-linux.sh -o download-linux.sh
less download-linux.sh
bash download-linux.sh --destination ./spotify-tui-030
bash ./spotify-tui-030/install.sh
~/.local/bin/spotify-tui --demo
~/.local/bin/spotify-tui
```

Linux x86_64, glibc 2.39+, libgcc_s, PipeWire/PulseAudio and your own Spotify/Soloist setup are required. Premium is needed for a personal provider key. Soloist is downloaded separately from Spotify. Credentials remain in your keyring and existing XDG directories. The tray needs panel support and a terminal installed for reopening. See the [tray/update guide](../SETUP.md#tray-and-updates).

## Validation

Go race checks, formatting and vet; Rust provider bridge tests, formatting and clippy. New regression checks cover provider-confirmed pause, queued toggles, delayed UI state, Ctrl-U while searching, numeric stable-version selection, archive corruption, unsafe paths/links, unmanaged installations and atomic activation with a retained rollback build. Package checks exercise the downloader and installer with paths containing spaces.

Published-download, installed-tray and live playback results are recorded in [implementation notes](../IMPLEMENTATION.md). No local `dist` binary is used for the live release acceptance checks.

## Known limits

Genuine offline downloads remain unsupported and required for the full original app. No ad-free promise for Free accounts. Search is limited to ten results; full liked-song sequencing, playlist offsets, MPRIS and long-session memory/stability checks remain outstanding. Provider restoration and connectivity can occasionally stall. `c` restarts the helper. Update restart can interrupt audio; track restoration still depends on provider availability. Checksums are unsigned. This stable version label does not imply every planned feature is finished.
